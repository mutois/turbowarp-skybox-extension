# TurboWarp 3D Skybox Extension

美しい星空を3Dパノラマのように映し出せるTurboWarp用拡張機能です。cubemap対応、スプライトコスチューム読み込み対応で、様々な3D背景表現が可能です。

## ✨ 機能

- **3Dパノラマスカイボックス表示** - 360度の美しい星空背景
- **3D星空モード** - 立体的に配置された2000個の星
- **cubemap対応** - 6面キューブマップの読み込み対応
- **ファイル読み込み** - ストレージから直接画像/cubemapを読み込み
- **スプライトコスチューム対応** - スプライトのコスチュームをテクスチャとして使用
- **リアルタイム制御** - 回転、ズーム、明度をブロックで自由に制御

## 📦 インストール

1. TurboWarp（https://turbowarp.org）を開く
2. 拡張機能を追加 → 「カスタム拡張機能を読み込む」
3. 以下のURLを入力：
   ```
   https://raw.githubusercontent.com/mutois/turbowarp-skybox-extension/main/turbowarp用拡張機能.js
   ```

## 🎮 使い方

### 基本的な使用方法

```
「スカイボックスを表示」
「３D星空を表示」
```

### 表示モード

| ブロック | 説明 |
|---------|------|
| スカイボックスを表示 | 通常のスカイボックスを表示 |
| ３D星空を表示 | 立体的な星空を表示（約2000個の星） |
| デフォルト星空を表示 | 初期状態の星空背景に戻す |
| スカイボックスを非表示 | スカイボックスを非表示にする |

### 回転制御

```
スカイボックスを X [0] Y [0] Z [0] 度回転
X軸を [10] 度回転
Y軸を [10] 度回転
Z軸を [10] 度回転
```

### ズーム・明度制御

```
スカイボックスをズーム [1]    // 1 = 等倍、2 = 2倍ズーム
明度を [100] に設定            // 0～200 (100がデフォルト)
```

### テクスチャ読み込み

#### 方法1: ファイルから読み込む（推奨）
```
ファイルから画像を読み込む
```
- 単一ファイルを選択：通常のスカイボックステクスチャとして使用
- 6ファイルを選択：cubemapとして使用

#### 方法2: cubemapをファイルから読み込む
```
ファイルから cubemap を読み込む (6ファイル選択)
```
6つの面（上下左右前後）の画像を選択してください

#### 方法3: URLから読み込む
```
URL [https://example.com/skybox.png] から画像を読み込む
```

#### 方法4: スプライトコスチュームから読み込む
```
スプライト [Sprite1] のコスチューム [0] をテクスチャに設定
```

```
スプライト [Sprite1] のコスチューム [0,1,2,3,4,5] をcubemapに設定 (カンマ区切り)
```

## 🎨 cubemap形式について

cubemap（キューブマップ）は、6つの正方形画像で3D空間を囲む方法です。以下の順序で指定します：

1. **上面** (Top) - +Y
2. **下面** (Bottom) - -Y
3. **前面** (Front) - +Z
4. **背面** (Back) - -Z
5. **右面** (Right) - +X
6. **左面** (Left) - -X

### cubemap形式の画像の作成方法

- Photoshopなどで6つの同サイズの正方形画像を作成
- 各面が512×512以上の解像度を推奨
- PNG形式、JPG形式両対応

## 💾 データ永続性について

### ✅ 永続的に保存される
- **スプライトコスチューム** - プロジェクト内に保存
- **URLリンク** - 外部サーバーから読み込む

### ⚠️ 永続的に保存されない
- **ファイルアップロード** - セッション中のみ有効（プロジェクト再読み込みで消失）
- **解決方法**：重要な画像はスプライトのコスチュームとして登録してください

## 📝 サンプルコード

### 基本的な星空回転
```
「スカイボックスを表示」ブロック
「３D星空を表示」ブロック
「ずっと」の中に
  「Y軸を [1] 度回転」ブロック
```

### インタラクティブな制御
```
「スカイボックスを表示」ブロック
「マウスが移動した時」イベント
  「スカイボックスを X [マウスのY] Y [マウスのX] Z [0] 度回転」
```

### ズーム制御
```
「上矢印キーが押された」
  「スカイボックスをズーム [ズーム + 0.1]」

「下矢印キーが押された」
  「スカイボックスをズーム [ズーム - 0.1]」
```

## 🛠️ 技術仕様

- **3Dライブラリ** - Three.js r128
- **レンダリング** - WebGL
- **対応形式** - PNG, JPG, WebP
- **推奨解像度** - 1024×1024以上
- **ブラウザ要件** - WebGL対応ブラウザ

## 🐛 トラブルシューティング

### 画像が表示されない
- ファイル形式がサポートされているか確認（PNG/JPG推奨）
- CORS（クロスオリジン）の問題がないか確認
- URLが正確か確認

### cubemapが認識されない
- 正確に6ファイルを選択したか確認
- ファイルが正方形画像か確認

### パフォーマンスが低い
- 3D星空の星数が多い場合、ブラウザが重くなる可能性
- 他のタブを閉じるか、ズームアウトしてみてください
